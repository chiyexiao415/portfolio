# 陈宇萱 · PLAYER FILE

游戏行业求职用的作品集网站，纯静态 HTML / CSS / JS，无框架、无构建步骤。

## 文件结构

```
portfolio/
├─ index.html      页面骨架（启动画面、主菜单、内容弹层、桌宠、图片放大层）
├─ style.css       全部样式，深浅两套主题在文件里集中定义
├─ script.js       所有文字内容在 DATA 对象里 + 交互逻辑（菜单、主题、桌宠）
├─ assets/         简历、游戏截图、案例图（assets/case）和轻量预览（assets/previews）
└─ README.md
```

长图放在固定高度的框里，电脑可直接滚动，手机可在图内上下滑动。页面优先读轻量 WebP 预览，其他图接近可见区域再加载；「查看长图」和放大入口仍使用未改动的原图。

## 怎么打开

- 直接双击 `index.html` 就能看，不需要服务器
- 或者在文件夹里起一个本地服务：`npx serve .`

## 当前完成度

- **主界面**：姓名、方向标签、桌宠停靠位和 6 个入口，只在选中的入口下显示一行提示。首次打开默认亮色，右上角可切换并记住选择。链接加 `?layout=classic` 可对照旧布局。
- **桌宠向导**：首次进入首页时跳进停靠位；用鼠标或手指拖到想放的位置，点击换一句。
- **角色档案**：左侧信息卡（学校 / 专业 / 电话 / 邮箱 / 毕业 / 核心优势 / 简历链接），右侧教育背景、关于我、个人技能、简历图
- **游戏经历**：7 个品类（ARPG / 竞技 / MMO / FPS / 女性向 / 剧情向 / 其他），每个品类有表格、游戏截图、ALSO PLAYED、PLAYER'S NOTE
- **经历**：网易互娱 + 赢商网两段，简历式排版，每段下面有结果数据
- **技能树**：内容 × AI、营销 × 数据、达人合作、赛事执行、工具
- **作品**：三个案例统一用暖色入口卡片，分别是官方内容与社媒运营、达人合作与账号运营、数据整理。官号页用坐标图展示四个项目，窄屏改为单列；万国霸业区分资料片宣发和潜龙争霸赛两条内容线。
- **联系方式**：手机、微信、邮箱、城市，均已在页面公开（用户确认可公开）

## 改内容

打开 `script.js`，找到 `DATA`，每个板块的 HTML 都在对应对象里。图片放进 `assets/`，文件名和代码里写的一致即可。

## 部署
